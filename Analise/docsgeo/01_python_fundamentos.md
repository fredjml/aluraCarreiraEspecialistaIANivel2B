# Fundamentos de Python para geocientistas

Python é uma linguagem adequada para automação, scripts, análise de dados e desenvolvimento rápido. A trilha inicial deve cobrir execução do interpretador, tipos básicos, coleções, controle de fluxo, funções, módulos, entrada e saída, tratamento de exceções, classes e ambientes virtuais.

Para uma transição de geociências para dados, o aprendizado deve combinar conceitos da linguagem com problemas pequenos e reproduzíveis: limpeza de tabelas, conversão de unidades, leitura de arquivos, cálculo de estatísticas e geração de relatórios. O tutorial oficial presume alguma familiaridade geral com programação e não substitui exercícios práticos.

Tópicos recuperáveis: Python, primeira linguagem, funções, módulos, exceções, arquivos, orientação a objetos, automação, ambiente virtual.
