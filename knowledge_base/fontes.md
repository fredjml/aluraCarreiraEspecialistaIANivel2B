# Política da base aprovada

Esta base contém apenas materiais locais revisados para o piloto do GeoAI Mentor. Arquivos externos, segredos, dados pessoais e documentos sem autorização não devem ser copiados para este diretório.

As respostas devem indicar o nome do arquivo usado como fonte. Quando nenhum trecho for relevante, o mentor deve informar que não encontrou evidência na base aprovada.
