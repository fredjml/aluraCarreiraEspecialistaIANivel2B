# Critérios de avaliação do piloto RAG

O piloto é aprovado quando recupera uma fonte pertinente para perguntas sobre Python e portfólio, não recupera evidência para uma pergunta fora da base, mantém os arquivos localmente e inclui o nome da fonte no contexto enviado ao modelo.

Não há ingestão automática. Atualizações exigem revisão humana do arquivo Markdown e execução dos testes automatizados.
