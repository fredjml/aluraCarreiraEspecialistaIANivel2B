# Análise de dados tabulares com pandas

O pandas organiza dados tabulares principalmente em `DataFrame`. Ele oferece leitura e escrita de CSV, Excel, SQL, JSON e Parquet, além de seleção de linhas e colunas, tratamento de valores ausentes, criação de variáveis, agregações, junções, reformatação e séries temporais.

Em geociências, pandas é útil para dados de poços, amostras, estações, inventários, medições laboratoriais e catálogos. Um fluxo básico deve inspecionar tipos, unidades, valores ausentes e duplicidades antes das estatísticas ou visualizações. Operações vetorizadas são preferíveis a laços linha a linha sempre que possível.

Tópicos recuperáveis: pandas, DataFrame, CSV, Excel, SQL, Parquet, limpeza, valores ausentes, groupby, merge, séries temporais.

Fonte oficial: [Getting started — pandas](https://pandas.pydata.org/docs/getting_started/).
